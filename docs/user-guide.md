# Руководство пользователя

RuVox — локальное приложение для прослушивания русских текстов и статей. Синтез
речи идёт на вашем компьютере: текст никуда не отправляется. Сеть нужна только
для разового скачивания моделей, проверки обновлений и импорта текста по ссылке.

Интерфейс состоит из трёх частей: сверху — плеер, слева — очередь записей,
справа — текст выбранной записи с подсветкой читаемого слова.

```text
┌────────────────────────────────────────────────────────────────┐
│ [>]  ─────────●────────  12:34 / 45:00  1.0x  ──●──  [настр.]  │
├──────────────────────┬─────────────────────────────────────────┤
│ Очередь              │ Введение в Rust                         │
│ [Добавить] [v]       │ 3 ноября 2026 · Готово · TeraTTSv2      │
│ [Поиск по записям]   │ [Markdown | Исходный]  [Узко|Широко] …  │
│ > Введение в Rust  > │ ─────────────────────────────────────── │
│   Заметка про Wasm   │ Текст статьи; читаемое слово подсвечено │
│   Ещё одна запись    │ по ходу воспроизведения.                │
└──────────────────────┴─────────────────────────────────────────┘
```

Ниже мокапы показывают только тот элемент, о котором идёт речь в разделе;
рамка окна и остальные панели опущены.

## 1. Первый запуск

По умолчанию RuVox работает на движке **TeraTTSv2**. Его модель весит около
410 МБ и скачивается один раз: при первом запуске появляется предложение
загрузить бандл.

```text
┌─ Движок по умолчанию — TeraTTSv2 ─────────────────────────────┐
│ Он естественнее читает русскую прозу, английские термины и    │
│ код. Для работы нужен бандл моделей ~410 МБ — скачивается     │
│ один раз, синтез идёт локально. Цена: первый синтез медленнее │
│ и памяти нужно больше (пик ~3,9 ГиБ).                         │
│                                                               │
│ [Остаться на Piper]                   [Скачать (~410 МБ)]     │
│ Быстрее и легче: Silero (нативный) (~230 МБ) — в Настройках.  │
└───────────────────────────────────────────────────────────────┘
```

- **Скачать** — модель загружается с прогрессом, после чего движок включается
  сразу, без перезапуска.
- **Остаться на Piper** — сеанс проходит на встроенном Piper без скачивания.
  Отказ не сохраняется: при следующем запуске предложение вернётся, пока
  бандл не установлен.

Движки и их модели:

| Движок | Модель | Когда подходит |
|--------|--------|----------------|
| TeraTTSv2 | ~410 МБ, по запросу | По умолчанию: естественнее читает прозу, английские термины и код |
| Silero (нативный) | ~230 МБ, по запросу | Быстрее и легче TeraTTSv2 |
| Piper | встроен, без скачивания | Самый быстрый старт и минимальные требования |
| Silero (Python) | нужен Python-сайдкар `ttsd` | Необязательный запасной вариант; в slim-сборке недоступен |

Переключить движок и скачать модели можно позже: **Настройки → Движок и
голос**. Скачиванием, обновлением и удалением моделей управляет отдельное окно
**«Модели и голоса»** (кнопка «Открыть» в том же разделе): там видны версии,
размер на диске, активная модель, голоса Piper и кнопка «Проверить
обновления». Активную модель нельзя обновить или удалить — сначала
переключитесь на другой движок.

Первый синтез после запуска всегда дольше последующих: TeraTTSv2 холодно
загружает модель примерно за 7 секунд (на референсной машине), Silero
(нативный) — примерно за 0,5 секунды; Piper готов сразу. Дальше синтез идёт в
фоне, и длинный текст может занять десятки секунд. Готовность записи приходит
уведомлением; пока идёт синтез, можно добавлять другие тексты.

## 2. Добавление текста

Добавить текст можно пятью способами:
- **Из буфера обмена** — кнопка **«Добавить»** (основная часть split-кнопки)
  или вставка `Ctrl+V` (`Cmd+V`) в любое место окна, кроме полей ввода.
- **Перетаскиванием** — файл `.txt`, `.md`, `.html`/`.htm` или ссылка
  `http(s)://…` бросается на окно; пока файл над окном, показывается подсказка
  «Отпустите, чтобы добавить».
- **Через меню «Файл…»** — обычный выбор файла; кодировка определяется
  автоматически.
- **Через «Файл с кодировкой…»** — тот же выбор файла, но сразу открывается
  окно кодировки с предпросмотром; здесь кодировку можно переопределить
  вручную.
- **Через «По ссылке…»** — вставьте адрес страницы и нажмите «Загрузить»;
  RuVox скачает страницу и извлечёт читаемый текст.

```text
┌─ Очередь ─────────────────────────┐
│ [Добавить] [v]                    │
│           ┌────────────────────┴──┐
│           │ Файл…                 │
│           │ Файл с кодировкой…    │
│           │ По ссылке…            │
│           └───────────────────────┘
│ [Поиск по записям]                │
```

Кодировка (UTF-8, CP1251, KOI8-R, CP866 и другие) определяется автоматически по
BOM и содержимому. Если в предпросмотре видны кракозябры, выберите кодировку в
окне «Кодировка файла» — текст перечитается сразу, до добавления в очередь.
Кнопка «Продолжить» передаёт исправленный текст в обычный предпросмотр.

Если включён предпросмотр (по умолчанию), перед синтезом открывается окно
**«Предпросмотр нормализации»** — см. следующий раздел. Отключить его можно
галочкой «Больше не показывать этот диалог» в предпросмотре или переключателем
**Настройки → Чтение текста → «Показывать диалог предпросмотра перед
синтезом»**.

## 3. Превью

Перед синтезом RuVox показывает, что именно будет прочитано вслух. Окно
предпросмотра плавающее: его можно перетаскивать за заголовок, растягивать за
края и закрыть клавишей `Esc`. Слева — оригинал, справа — текст после
нормализации.

```text
┌─ Предпросмотр нормализации ───────────────────────── [?] [x] ───┐
│ Слева — исходный текст, справа — то, что будет произнесено.     │
│ ┌─ Оригинал ───────────────┐ ┌─ После нормализации ──────────┐  │
│ │ Вызови getUserData()     │ │ Вызови гет юзер дата          │  │
│ │ через API…               │ │ через эй пи ай…               │  │
│ └──────────────────────────┘ └───────────────────────────────┘  │
│ [В словарь]  [Авто (Markdown) v]  [ ] Синхронный скроллинг      │
│ [ ] Больше не показывать этот диалог                            │
│             [Читать сейчас] [Отмена] [Редактировать]            │
│                                      [Синтезировать]            │
└─────────────────────────────────────────────────────────────────┘
```

- **Формат источника** — «Авто» (определяется по содержимому), «Обычный
  текст», «Markdown» или «HTML». Формат влияет на нормализацию: из HTML
  извлекается читаемый текст, Markdown разбирается по смыслу. Если
  автоопределение ошиблось, выберите формат вручную.
- **Редактировать** — левая панель становится полем ввода. Правка применяется
  к тому, что уйдёт в синтез; правая панель пересчитывается с небольшой
  задержкой.
- **«В словарь»** — выделите в любой панели ровно одно слово (латиницей или
  по-русски) и нажмите кнопку: откроется редактор словаря с заполненным словом.
  После сохранения нормализация в предпросмотре пересчитается автоматически.
- **Читать сейчас** — начать воспроизведение сразу после готовности записи.
- **Синтезировать** — создать запись в очереди и запустить синтез.
- **Синхронный скроллинг** — прокручивать обе панели вместе.
- **Больше не показывать этот диалог** — отключить предпросмотр для будущих
  добавлений (то же, что переключатель в настройках).

Тот же диалог открывается при перегенерации записи (см. «Очередь»), но в
режиме подтверждения: изменить текст, формат и отключить диалог нельзя;
остаются «Перегенерировать», «Читать сейчас» и быстрый переход в словарь по
выделенному слову.

## 4. Очередь

Каждая запись в очереди — карточка с заголовком, статусом, длительностью и
кнопкой воспроизведения. Заголовок берётся из первой содержательной строки
текста; его можно изменить в шапке над текстом (см. «Воспроизведение»).
Заголовок и заметка также участвуют в поиске.

```text
┌─ Очередь ───────────────────────────────────────┐
│ [Добавить] [v]                                  │
│ [Поиск по записям]                              │
│ ┌─────────────────────────────────────────────┐ │
│ │ Введение в Rust                    [Готово] │ │
│ │ 12:34                                  [>]  │ │
│ └─────────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────────┐ │
│ │ Заметка про Wasm                [Обработка] │ │
│ │ Синтез… 0:42  [Отменить]                    │ │
│ └─────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────┘
```

Статусы: **Ожидание** (в очереди), **Обработка** (идёт синтез, видно
прошедшее время и кнопку «Отменить»), **Готово**, **Играет**, **Ошибка**,
**Отменено**. Синтез идёт в фоне; готовность и ошибки приходят уведомлениями
(их можно отключить в настройках).

- **Поиск** фильтрует записи по заголовку, заметке и исходному тексту без учёта
  регистра. `Ctrl+F` (`Cmd+F`) ставит курсор в поле поиска, `Esc` очищает его.
  Если играющая запись ушла из видимой области, появляется кнопка «К читаемому».
- **Контекстное меню** открывается правой кнопкой по карточке.

```text
┌──────────────────────────────┐
│ Воспроизвести                │
│ Сохранить аудио как…         │
│ Перегенерировать аудио       │
│ Параметры записи…            │
│ Отменить синтез              │
├──────────────────────────────┤
│ Удалить                      │
└──────────────────────────────┘
```

- **Воспроизвести** — запустить готовую запись.
- **Сохранить аудио как…** — сохранить запись в WAV или Ogg Opus. Формат
  выбирается в системном диалоге сохранения; после успеха показывается путь к
  файлу.
- **Перегенерировать аудио** — заново синтезировать текст текущим движком и
  голосом. Сначала открывается предпросмотр с подтверждением; старой записью
  можно пользоваться, пока не будет готова новая. Если перегенерация не
  удалась, прежнее аудио остаётся и на карточке появляется предупреждение.
- **Параметры записи…** — что именно создало текущее аудио: источник, движок,
  голос, частота дискретизации, модель и её контрольная сумма, версия
  приложения, режим код-блоков, контрольная сумма текста, кодек и размер
  аудио, длительность, дата генерации и номер генерации. То же окно
  открывается двойным щелчком по карточке (если параметры сохранены).
- **Отменить синтез** — остановить запись, которая ждёт или синтезируется.
- **Удалить** — удалить запись вместе с аудиофайлом; действие подтверждается.

Если синтез завершился ошибкой, карточка хранит причину и кнопку «Повторить»,
а длинный текст ошибки можно развернуть кнопкой «Показать полностью».

## 5. Воспроизведение

Плеер находится в верхней панели и управляет выбранной записью.

```text
┌────────────────────────────────────────────────────────────────────┐
│ RuVox  [>]  ────────●────────  12:34 / 45:00  1.0x  ──●── [настр.] │
└────────────────────────────────────────────────────────────────────┘
```

- **Воспроизвести / Пауза** — кнопка `[>]`; при паузе повторное нажатие
  продолжает с того же места.
- **Позиция** — ползунок и время `MM:SS / MM:SS`; щёлкните или перетащите
  ползунок, чтобы перемотать. Стрелки `←`/`→` перематывают на 5 секунд.
- **Скорость** — от 0,5× до 3×; значение сохраняется между запусками. Колесо
  мыши над числом меняет скорость на 0,1.
- **Громкость** — ползунок в процентах.
- **Шестерёнка** — открыть настройки.

Во время чтения текущее слово подсвечивается в тексте; на паузе подсветка
остаётся. Если перемотать, подсветка переходит к слову на новой позиции.
Нажмите `Space`, чтобы поставить на паузу или продолжить.

Над текстом расположена шапка записи:

- **Заголовок** — щёлкните по нему или по карандашу, чтобы переименовать.
  `Enter` сохраняет, `Esc` отменяет; пустой заголовок возвращает автоматический
  вариант из первой строки текста.
- **Заметка** — кнопка «Добавить заметку»; `Ctrl+Enter` сохраняет, `Esc`
  отменяет. Длинная заметка сворачивается до двух строк с кнопкой «Показать
  полностью».
- **Метаданные** — дата добавления, статус, движок и голос текущей записи
  (для ещё не озвученной записи — «не озвучено» и «—»).
- **Формат текста** — переключатель «Markdown | Исходный» (или «HTML |
  Исходный»). У обычного текста переключателя нет: показывается только
  исходный вид.
- **Ширина и масштаб чтения** — «Узко | Широко» и `[−] 100% [+]` с кнопкой
  сброса. Масштаб меняется от 80 до 200 % и увеличивает весь текст, код,
  таблицы и картинки; оба выбора сохраняются для приложения и не сбрасываются
  при переключении записей.

Текст только для чтения: ссылки не открываются, но их адрес можно скопировать.
Правый клик по ссылке даёт «Скопировать адрес ссылки», по выделенному тексту —
«Копировать», по картинке — «Скопировать изображение» и «Скопировать адрес
изображения». Если выделено ровно одно слово, в меню появляется «В словарь».
`Ctrl+A` (`Cmd+A`) внутри текста выделяет только текст записи, а `Ctrl+C`
(`Cmd+C`) на ссылке копирует её адрес. Mermaid-диаграммы можно увеличить
щелчком; широкие таблицы и блоки кода прокручиваются внутри колонки.

## 6. Настройки

Настройки открываются шестерёнкой в плеере. Окно разделено на разделы; слева —
поиск и список разделов, справа — настройки выбранного раздела. Внизу
показывается, сколько полей изменено, и кнопки «Сбросить» и «Сохранить».

```text
┌─ Настройки ─────────────────────────────────────────────── [x] ─┐
│ [Поиск по настройкам]                                           │
│ ┌─ Разделы ─────────┐ ┌─ Чтение текста ───────────────────────┐ │
│ │ Движок и голос    │ │ Озвучка блоков кода: [Кратко|Читать]  │ │
│ │ Чтение текста   • │ │ Английский текст: [Авто|Нативно|…]    │ │
│ │ Уведомления       │ │ [x] Показывать диалог предпросмотра   │ │
│ │ Хранилище         │ │ Ширина чтения: [Узко|Широко]          │ │
│ │ Интерфейс         │ │ Масштаб чтения: [-] 100% [+] [↺]      │ │
│ │ Словарь           │ │                                       │ │
│ │ О программе       │ │                                       │ │
│ └───────────────────┘ └───────────────────────────────────────┘ │
│ Изменено: 1                         [Сбросить] [Сохранить]      │
└─────────────────────────────────────────────────────────────────┘
```

Поиск ищет по названиям настроек (включая английские подписи и синонимы),
подсвечивает совпадения и скрывает разделы без совпадений. `Enter` переходит к
первому найденному полю, `Esc` очищает запрос; повторный `Esc` закрывает окно.
Точка у раздела означает несохранённые изменения. В узком окне список разделов
заменяется выпадающим списком.

- **Движок и голос** — выбор движка, голос движка (TeraTTSv2, Piper или
  Silero), частота дискретизации (8000/24000/48000 Гц; Piper её игнорирует) и
  вход в «Модели и голоса». Недоступный движок показан с причиной; если
  сохранённый движок недоступен, выбирается Piper и появляется предупреждение.
- **Чтение текста** — «Озвучка блоков кода»: «Кратко» (блок заменяется фразой
  «далее следует пример кода на <язык>») или «Читать полностью» (TeraTTSv2 и
  Piper читают код сами, Silero проговаривает его с нормализацией). «Английский
  текст»: «Авто» (как умеет движок), «Нативно» (английским голосом движка) или
  «По-русски» (транслитерация); если движок не умеет английский нативно, выбор
  сохраняется, но текст читается по-русски. Здесь же переключатель диалога
  предпросмотра, ширина чтения и масштаб.
- **Уведомления** — о готовности аудио и об ошибках синтеза.
- **Хранилище** — максимальный размер кэша (не меньше 100 МБ), папка данных с
  кнопкой «Открыть папку» и кнопка «Очистить кэш…». Очистка удаляет самые
  старые записи до указанного размера, может удалить и сами тексты, а кнопка
  «Очистить полностью» удаляет всё аудио (и тексты, если включён
  соответствующий флажок). Действие необратимо и подтверждается.
- **Интерфейс** — «Сворачивать в трей при закрытии окна», тема оформления
  (светлая, тёмная, авто) и язык интерфейса (русский/английский; применяется
  сразу после выбора).
- **Словарь** — число записей и кнопка «Открыть…» (см. следующий раздел).
- **О программе** — версия, «Проверить обновления» и папка с логами.

Автообновление работает в Windows-установщике и Linux AppImage. При наличии
новой версии появляется уведомление с выбором «Обновить и перезапустить» или
«Позже»; установка проверяет подпись и перезапускает приложение. В сборках из
`.deb` и Nix обновление через приложение недоступно — раздел обновлений не
показывается, обновляйтесь вместе с системой.

## 7. Словарь

Словарь задаёт произношение отдельных слов, которые движок читает неверно:
`IPv6` → «айпи ви шесть», `замок` → «зам+ок». Словарь ищет точную форму слова
без учёта регистра; слово может быть латиницей или по-русски, с цифрами и
дефисом внутри (`UTF-8`, `e-mail`). Для русских слов можно перечислить
дополнительные формы (`замка`, `замке`) — они будут читаться так же.

Словарь состоит из общего набора и наборов отдельных движков. Общий действует
везде, набор движка — только для него и важнее общего при совпадении слова.
Набор выбирается в верхней части редактора.

```text
┌─ Словарь произношений ──────────────────────────────────── [x] ─┐
│ Словарь: [Общий v]   [Поиск по словам]  [Импорт…] [Экспорт…]    │
│ ┌─ Слово ──┬─ Произношение ───────────────────────────────────┐ │
│ │ IPv6     │ айпи ви шесть                                    │ │
│ │ замок    │ зам+ок                     [>] [изм.] [x]        │ │
│ └──────────┴──────────────────────────────────────────────────┘ │
│ ┌─ Добавить слово ────────────────────────────────────────────┐ │
│ │ Слово: [IPv6________]              [>] Прослушать           │ │
│ │ Как произносить: [айпи ви шесть]   [>] Прослушать           │ │
│ │ Формы слова: [замка, замке____________________]             │ │
│ │ [Сохранить] [Отмена]                                        │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

- **Ударение** задаётся знаком `+` перед ударной гласной: `Москв+а`. Движки
  без поддержки ударения отбрасывают `+` и читают слово без метки.
- **Прослушать** — кнопки `[>]` у полей «Слово» и «Как произносить» (#349)
  озвучивают текущее чтение слова и набранное произношение активным движком.
  Воспроизведение записи ставится на паузу, а повторное прослушивание того же
  текста берётся из кэша. Ударение в прослушивании учитывается только у
  движков, которые его поддерживают.
- **В словарь из текста** — выделите одно слово в просмотрщике или в
  предпросмотре и выберите «В словарь» в контекстном меню или нажмите
  кнопку. Сохранение из просмотрщика дальше ничего не спрашивает: когда
  запись понадобится, переозвучьте её из контекстного меню записи
  («Перегенерировать аудио»); при неудаче прежнее аудио останется.
- **Импорт и экспорт** — файлы TOML; при импорте выбирается «Объединить»
  (слова из файла побеждают при совпадении) или «Заменить список». Файл можно
  просто перетащить в окно словаря. Словарь хранится в файле
  `user_dictionary.toml` рядом с `config.json` и правится вручную; после
  правки на диске перезапустите приложение.
- Запись, переопределяющая встроенное произношение, помечается значком
  «переопределяет встроенное».

## 8. Трей

По умолчанию закрытие окна завершает приложение. Фоновый режим включается
переключателем **Настройки → Интерфейс → «Сворачивать в трей при закрытии
окна»**. После включения в области уведомлений появляется значок RuVox, и
закрытие окна прячет его в трей, не завершая приложение: синтез продолжается,
а вернуться можно из меню значка.

```text
(значок RuVox в области уведомлений)
┌──────────────────┐
│ Открыть окно     │
├──────────────────┤
│ Добавить         │
├──────────────────┤
│ Выход            │
└──────────────────┘
```

- **Открыть окно** — показать и сфокусировать окно; то же делает щелчок левой
  кнопкой по значку.
- **Добавить** — прочитать буфер обмена и сразу добавить запись в очередь,
  не открывая окно.
- **Выход** — полностью закрыть приложение.

При скрытии окна воспроизведение останавливается, а после возврата плеер снова
готов к работе — нажмите `[>]`, чтобы продолжить. Если переключатель выключен,
значка в трее нет, и закрытие окна завершает приложение.

## 9. Горячие клавиши

Работают только при активном окне RuVox; глобальных горячих клавиш нет.

| Клавиши | Действие |
|---------|----------|
| `Space` | Воспроизведение / пауза |
| `←` / `→` | Перемотка назад / вперёд на 5 секунд |
| `Ctrl+F` / `Cmd+F` | Перейти в поиск по очереди |
| `Esc` | Закрыть активное окно; в поиске сначала очистить запрос; в заголовке/заметке — отменить правку |
| `Ctrl+A` / `Cmd+A` | Выделить весь текст записи (когда фокус внутри текста) |
| `Ctrl+C` / `Cmd+C` на ссылке | Скопировать адрес ссылки (когда фокус или выделение на ссылке в тексте) |

## 10. Траблшутинг

**Не скачивается бандл моделей.** Предпросмотр первого запуска и окно
«Модели и голоса» показывают ошибку и позволяют повторить. Проверьте сеть,
прокси и свободное место на диске. Если канал обновлений недоступен, уже
установленные модели продолжают работать — это не блокирует синтез. Удалить и
скачать модель заново можно в «Модели и голоса», но только после переключения
на другой движок: активную модель удалять нельзя.

**Нет звука.** Проверьте громкость в плеере и звуковом устройстве системы.
Воспроизведение идёт через mpv: в Windows и AppImage он встроен, в `.deb`
нужен системный `mpv` (он ставится зависимостью), а в Nix-сборке mpv
попадает в `PATH`. Если mpv не найден или не запускается, при нажатии
`[>]` появляется ошибка воспроизведения; подробности — в логах
(Настройки → О программе → «Папка с логами»). Запись должна быть в статусе
«Готово»: пока идёт синтез, играть нечего.

**Кракозябры вместо текста.** Кодировка определилась неверно. Для файла
используйте «Файл с кодировкой…» и выберите правильную кодировку в окне с
предпросмотром — текст перечитается сразу. Уже добавленную запись
отредактировать нельзя (меняются только заголовок и заметка): удалите её и
добавьте текст заново с верной кодировкой. При вставке из браузера RuVox
старается использовать HTML-вариант буфера обмена, поэтому разметка не
превращается в мусор.

**Слово произносится неправильно.** Выделите слово в тексте, выберите
«В словарь» и задайте произношение; для русского слова можно добавить формы, а
ударение — знаком `+` (`зам+ок`). Проверьте результат кнопкой прослушивания в
редакторе. Движки, не поддерживающие ударение, проигнорируют `+`. Если слово
добавили из просмотрщика, после сохранения закройте редактор: запись
обновится, когда вы перегенерируете её из контекстного меню («Перегенерировать
аудио»). Если слово читается неверно из-за
английского режима, проверьте **Настройки → Чтение текста → «Английский
текст»**: «Авто» оставляет произношение движку, «По-русски» включает
транслитерацию.

**Синтез завершился ошибкой.** Причина сохраняется на карточке записи; нажмите
«Повторить» или «Перегенерировать аудио». Если ошибка повторяется, проверьте
выбранный движок и его модель в «Модели и голоса», а подробности найдите в
логах.

**Длинный текст синтезируется долго.** Это ожидаемо: TeraTTSv2 синтезирует
медленнее Piper, а первый запуск после старта включает загрузку модели. Синтез
идёт в фоне — можно продолжать работать с очередью.
